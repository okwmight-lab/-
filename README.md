프로젝트명: 아두이노 블루투스 모듈 기반 무선 제어 RC카 제작 프로젝트
기간: 2026.04.12 ~ 2026.05.03 

사용 기술 및 하드웨어
 Arduino IDE,아두이노 우노, 블루투스 모듈(HC-06), DC 기어 모터 2개, 모터 드라이버(L298N),배터리9v,1.5v

제작과정:DC 기어 모터와 모터 드라이버의 구동 원리를 학습한 뒤, 타이머 함수를 활용하여 10초 주기로 전진과 후진을 반복하는 코드를 구현하였다. 이후 블루투스 통신 모듈을 결합해 
스마트폰 앱과 아두이노 간의 시리얼 통신 체계를 구축하였으며, 스마트폰의 조이스틱 신호에 따라 좌우 바퀴의 속도를 무선으로 제어할 수 있는 자동차를 제작하였다. 
제작 과정에서는 기어 모터 2개를 동시에 구동할 때 전력이 부족해 모터가 정상적으로 작동하지 않거나, 아두이노와 모터 드라이버의 GND 연결 문제로 신호 오류가 발생하는 어려움이 있었다. 
이를 해결하기 위해 모터 드라이버 관련 기술 자료와 선배들의 작품을 참고하여 회로 연결을 수정하였고, 다양한 배터리 조합을 실험하며 모터 구동에 적합한 전압과 전류 조건을 찾아 안정적인 전원 공급 환경을 구축하였다. 
또한 단순 제어 방식으로는 차량의 좌우 회전 속도를 자연스럽게 조절하기 어려워 모터 드라이버의 ENA, ENB 핀을 활용한 PWM 제어 방식을 적용하였으며, 
이를 통해 0~255 단계로 좌우 바퀴의 속도를 세밀하게 조절하여 부드러운 회전이 가능한 무선 제어 자동차를 완성하였다.

느낀점
처음에는 코딩만 잘하면 자동차가 알아서 잘 굴러갈 줄 알았는 데 실제로는 배터리 연결 방식이나 GND 선 하나 제대로 연결하지 않으면 아예 작동조차 안 하거나 코드가 먹통이 되는 모습을 보았습니다.
아무리 좋은 코드를 짜도 하드웨어가 그렇지 않으면 소용없고, 반대로 기계를 잘 만들어도 안에 있는 코드가 부실하면 움직이지 않는다는 것을 깨달았습니다
그래서 이를 통해 기계공학에서 하드웨어와 소프트웨어가 얼마나 긴밀하게 연결되어 있는지를 많은 시간을 들여 알게되었으며 
눈에 보이지 않는 사소한 배선 하나와 코드 한 줄이 프로젝트 전체의 성공을 결정짓는다는 것을 알게 된 소중한 경험이었습니다.
